This Blender 5.1+ rig features:
* Inverse Kinematics w/ switching and snapping
* Modern rig controls
* Animation exporting to Project Zomboid
* Fully custom rig UI
* Direct importing of Project Zomboid assets
* Direct importing of modded assets
* Body texture systems
* Preset and custom shading systems
* ...and more!

This was supposed to be a simple update that only added a small UI for the rig, but quickly spiraled into something crazier with more and more features. 
I still have a lot more I'd like to do with this project, and I would really consider V4 to be the 'halfway point' towards the final vision.

# Installation
Either install the latest release from Releases (which is reccomended), or download the zipped Blend file straight from the repository.
